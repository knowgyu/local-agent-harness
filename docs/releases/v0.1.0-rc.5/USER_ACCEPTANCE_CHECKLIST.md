# v0.1.0-rc.5 사용 확인

사용 환경에서 각 항목을 통과·실패·미확인으로 기록하세요. 모의 서비스 결과와 실제 서비스 결과를 구분합니다.

## 사용자 환경 확인

- [ ] ZIP·manifest·SHA-256이 일치하고 새 설치 또는 업데이트가 완료된다.
- [ ] Codex CLI와 Claude Code에서 같은 설치·설정 안내를 확인할 수 있다.
- [ ] 사용자가 선택한 자료에서만 연결 후보를 찾고, 모르는 정보는 한 번에 질문한다.
- [ ] 비밀값은 로컬 UI에 입력하고, 제안된 범위 전체를 검토한 뒤 등록한다.
- [ ] 같은 요청을 반복해도 중복 등록이나 권한 증가가 발생하지 않는다.
- [ ] 만료·중단·실패 상태에서 기존 설정을 보존하고 다음 행동을 안내한다.
- [ ] 등록, 연결 시험, 실제 MCP 조회 결과가 대상별로 구분된다.
- [ ] 사용자가 선택한 실제 서비스 대상에서 승인한 MCP 조회가 성공한다.
- [ ] 설정·권한·Dashboard 매핑이 바뀌면 이전 읽기 증거를 현재 성공으로 사용하지 않는다.

## RC5에서 기록한 검증 증거

| 확인 | 결과 | 범위와 한계 |
|---|---|---|
| Codex CLI 0.162.1에서 `github_repository`, `setup_status` 호출 | 통과 | 모의 GitHub 대상에서 도구 응답이 성공했습니다. 대상별 `first_read.state=observed`, `client_attribution=not_observed`입니다. Codex 모델의 최종 응답도 PASS였습니다. |
| Claude Code 2.1.224 호출 | 차단·모델 미실행 | 도구 호출 전에 만료된 OAuth로 HTTP 401이 발생했습니다. |
| Codex CLI·Claude Code SDK 프로토콜 fixture | 통과 | fixture 결과이며 실제 Claude Code 호출을 검증하지 않습니다. |
| Windows 네이티브 Go 전체 테스트와 `go vet` | 통과 | 전체 테스트 34.82초, vet 0.99초로 종료 코드 0입니다. |
| Portable ZIP | 통과 | 빌드는 21초에 통과했습니다. 디버그 정보를 뺀 EXE 두 개의 바이트가 일치했고, ZIP 구성·개인정보 검사에서 11개 파일 구성을 확인했습니다. |
| Claude Desktop MCPB 2.1.2 | 통과 | validate·pack·info가 13.19초에 완료됐습니다. MCPB에는 `manifest.json`과 서버 실행 파일만 들어 있고, 실행 파일의 바이트가 ZIP과 일치합니다. |
| 최종 EXE의 stdio 상태 조회 검사 | 통과 | 분리된 환경에서 protocol 2025-11-25와 23개 도구를 확인했습니다. 상태 조회·안내 리소스가 정상 응답했고, 안내 바이트가 일치했습니다. 상태 조회 중 파일 변경은 없었으며 잘못된 인수는 거부됐습니다. |
| 설치·업데이트·중단 복구 | 통과 | Windows PowerShell 5.1·PowerShell 7.6.7의 작업 전용 합성 경로에서 10/10 흐름 통과. 실제 사용자 설치 경로는 검사하지 않았습니다. |
| 실제 GitHub Enterprise·Jenkins·Dashboard 및 Credential Manager | 미확인 | 실제 회사 서비스 연결과 OS 자격 증명 저장·삭제는 검증하지 않았습니다. |

테스트 및 패키지 근거는 [RC5 검증 요약](VALIDATION_SUMMARY.ko.md)을 참조하세요. 이 체크리스트의 모의 서비스 결과는 실제 서비스 호환성 확인을 대신하지 않습니다.
