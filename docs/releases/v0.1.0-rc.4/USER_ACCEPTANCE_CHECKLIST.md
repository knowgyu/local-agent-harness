# v0.1.0-rc.4 사용자 수용 체크리스트

이 체크리스트는 RC4 Windows 데스크톱 흐름과 새 사용 안내를 확인하기 위한 것입니다. 모바일은 사용하지 않으며 릴리스 게이트가 아닙니다. 실제 서비스·OS 자격 증명 저장소·클라이언트 검증은 선택 사항이며, 비운영 환경이 없으면 `미확인`으로 둡니다.

각 항목을 `통과`, `실패`, `미확인`으로 기록하세요. 합성 테스트와 실제 환경 확인을 구분하고, 실제 URL·토큰·사용자 이름·개인 경로·고객 데이터를 기록하지 마세요.

## 1. 배포 자산과 시작

- [ ] ZIP 자산 이름이 `release-manifest.json`에 나열되어 있다.
- [ ] manifest payload 파일의 SHA-256과 `SHA256SUMS.txt`의 해당 행이 일치한다. 체크섬 파일은 자신을 해시하지 않으며 파일 무결성만 확인한다.
- [ ] 파일이 서명되지 않은 사전 공개 후보임을 확인했다.
- [ ] ZIP의 설치·업데이트·제거 스크립트와 오프라인 문서 구성을 확인했다.
- [ ] 앱을 데스크톱 창에서 열고 **사용 가이드** 링크를 눌러 `/guide`가 표시되는지 확인했다.
- [ ] 언어를 한국어와 영어로 바꾸고 목차 링크, 설정 이동 링크, 문서 링크가 동작하는지 확인했다.
- [ ] 정적 안내가 설정·비밀값을 읽거나 원격 요청/MCP 도구 실행을 하지 않는다는 경계를 확인했다.

## 2. 안내에 따라 대상 하나를 등록하기

- [ ] 안내의 GitHub Enterprise, Jenkins, Dashboard 주소 예시가 `.invalid` 가상 주소이며 실제 주소와 구분됨을 확인했다.
- [ ] 실제 또는 비운영 주소로 후보를 확인할 경우, URL 후보 확인이 주소 모양을 파싱할 뿐 원격 연결 검사가 아님을 확인했다.
- [ ] 필드 후보, 대상 이름, Jenkins context/job 경로 또는 Dashboard proxy 경로를 직접 검토했다.
- [ ] 일반 설정 진행 상황 저장·재개가 가능하고 초안에 토큰·비밀번호·자격 증명 참조가 저장되지 않음을 확인했다.
- [ ] 임시 확인은 직접 버튼을 눌렀을 때만 원격 요청을 보냄을 확인했다.
- [ ] 고정 작업 범위 검토 후 명시적으로 새 대상을 등록했다. 기존 대상을 onboarding이 자동 수정하지 않음을 확인했다.

## 3. 예시와 실패 경로

- [ ] 자연어 요청 예시를 연결된 AI 클라이언트에 붙여넣는 것이며, JSON은 MCP 도구 인자 모양 예시임을 구분했다. 안내 페이지는 실행하지 않는다.
- [ ] GitHub 예시는 저장소/PR 메타데이터 범위이며 소스 파일·diff 읽기나 전체 코드 리뷰를 지원한다고 해석하지 않았다.
- [ ] Dashboard namespace 조회와 service bundle/environment에 매핑된 Deployment 진단을 구분했다. Catalog 목록이나 namespace 목록으로 mapping이 생성되지 않는다.
- [ ] 401/403, 시간 초과, VPN/proxy, 만료된 draft check가 안내한 재확인 경로와 일치하는지 확인했다.
- [ ] 로그인 교환·토큰 자동 추정·Dashboard 화면의 `1.7.0` 숫자를 인증 방식의 증거로 사용하지 않았다.

## 4. 클라이언트 설정과 첫 실제 조회 (선택 검증)

- [ ] 클라이언트별 수동 설정 안내를 확인하고, 실제 설정은 선택한 클라이언트에서 별도로 수행했다.
- [ ] Codex CLI 또는 ChatGPT 데스크톱 앱의 Codex 기능을 일반 ChatGPT 대화/Work 지원으로 해석하지 않았다.
- [ ] 실제 클라이언트에서 서버와 도구가 보이는지 확인했다. 문서 예시나 설정 파일 작성만으로 연결 통과라 기록하지 않았다.
- [ ] 비운영 대상의 허용 읽기 도구를 호출하여 서비스 데이터를 실제 반환받았다.
- [ ] 앱의 준비 상태에서 실제 MCP 첫 조회가 표시되는지 확인했다. 카탈로그 조회와 등록 대상 연결 테스트는 첫 읽기가 아니다.
- [ ] Claude Desktop용 `.mcpb`를 사용하는 경우, 패키지 검증과 실제 Desktop 설치·실행·도구 호출을 별도로 구분했다.

## 5. 실제 환경 검증 (선택)

- [ ] 실제 서비스 토큰, 읽기 권한, TLS/proxy/VPN 경로를 관리자와 확인했다.
- [ ] 실제 Windows Credential Manager 저장·조회·회전·삭제를 비운영 계정으로 확인했다.
- [ ] 선택한 AI 클라이언트의 설치, server/tool 표시, 실제 호출을 각각 확인했다.
