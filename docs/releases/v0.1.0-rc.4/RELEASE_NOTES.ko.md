# Local Agent Harness v0.1.0-rc.4

Windows x64용 서명되지 않은 사전 공개 후보입니다. 파일명과 SHA-256은 배포 자산의 `release-manifest.json` 및 `SHA256SUMS.txt`에서 확인하세요. 체크섬은 파일 손상·변경 여부를 대조하며 게시자 신원을 인증하지 않습니다.

## 이번 변경

- 앱 안에 한국어와 영어로 된 읽기 전용 사용 안내 화면 `/guide`를 추가했습니다. 상단의 **사용 가이드** 링크에서 열고, 항목별 바로가기와 설정 화면 링크로 필요한 단계에 이동할 수 있습니다.
- GitHub Enterprise, Jenkins, Kubernetes Dashboard의 URL 후보 확인부터 일반 초안 저장, 임시 확인, 고정 작업 범위 검토, 명시적 등록까지 실제 흐름을 따라가도록 안내합니다.
- 연결된 AI 클라이언트에 붙여넣을 자연어 요청과 MCP 도구 입력 예시, Harbor·SSH·Python의 상황별 예, 실패와 재개 시 확인할 내용을 제공합니다. 예시는 가상 이름과 `.invalid` 주소를 사용하며 자동 실행되지 않습니다.
- 카탈로그 목록, 등록 대상 연결 테스트, 성공한 외부 MCP 읽기의 차이를 설명합니다. MCP 연결 설정이나 도구 목록 확인만으로 실제 첫 서비스 읽기를 확인했다고 보지 않습니다.
- Codex CLI, Codex 기능을 갖춘 ChatGPT 데스크톱 앱, Claude Desktop 등 클라이언트 설정 설명의 적용 범위를 분명히 했습니다. 일반 ChatGPT 대화/Work 연결이나 특정 로컬 설치를 검증했다고 주장하지 않습니다.
- 오프라인 한국어 안내서 `USER_GUIDE.ko.md`를 Windows ZIP에 포함하고, 안내서에서 연결하는 `CLIENT_SETUP.md`와 `CLAUDE_DESKTOP.md`도 함께 제공합니다.
- RC3에서 설치·업데이트가 중단되어 남은 검증된 복구 기록을 RC4에서 이어 처리하도록 호환성을 보강했습니다. 인식되지 않는 중간·혼합 패키지 구성은 복구 대상으로 받아들이지 않습니다.

## 확인 범위

RC4의 현재 코드, 안내 화면과 배포 자산에 대한 검증 결과는 [검증 요약](VALIDATION_SUMMARY.ko.md)을 확인하세요. RC3 검증 결과는 RC4에서 다시 실행한 결과로 간주하지 않습니다. 실제 GitHub Enterprise, Jenkins, Dashboard 권한과 연결, Windows Credential Manager의 실제 저장·삭제, 실제 AI 클라이언트 설치·호출과 첫 외부 읽기는 별도 사용자 환경에서 확인해야 합니다.

## 사용 범위

UI 사용·수용 범위는 Windows 데스크톱입니다. 좁은 데스크톱 창도 포함합니다. 모바일은 사용하지 않으며 지원 목표나 릴리스 게이트가 아닙니다. 실제 자격 증명이나 사내 주소를 예시·요청문·이슈·스크린샷에 넣지 마세요.
