# v0.1.0-rc.4 검증 요약

## 범위

RC4는 Windows 데스크톱용 서명되지 않은 사전 공개 후보입니다. 다음 결과는 RC4에서 새로 실행한 확인만 기록합니다. RC3 검증은 재사용하지 않습니다. 실제 GitHub Enterprise, Jenkins, Dashboard, Windows Credential Manager 또는 AI 클라이언트 환경의 성공을 합성 테스트 결과로 대신하지 않습니다.

## 현재 RC4 검증

| 확인 | RC4 결과 |
| --- | --- |
| Go 전체 테스트 (`go test -count=1 ./...`) | 통과, 61.596초 |
| `go vet ./...` | 통과, 3.375초 |
| Windows x64 실행 파일 및 ZIP 빌드 | 최종 후보 빌드 통과; ZIP에 평면 구성원 11개 포함 |
| ZIP 구성·재현성·개인정보 표식 검사 | 두 번 빌드한 EXE가 바이트 단위로 일치; 개인정보 표식 검사 통과 |
| MCPB 검증/패키징/manifest 정보 | pinned `@anthropic-ai/mcpb` 2.1.2로 `validate`/`pack`/`info` 통과; RC4 manifest, `manifest.json`과 EXE 2개, ZIP 실행 파일과 바이트 일치 |
| 패키징된 실행 파일의 격리 stdio 초기화 및 도구 목록 | 통과; 프로토콜 `2025-11-25` 협상, 도구 22개 고유 이름 확인 |
| `/guide` 핸들러·정적 응답 테스트 | 위 전체 테스트에 포함되어 통과; 한국어/영어 렌더링, 잘못된 경로·메서드 거부, 보안 헤더, 설정 파일을 읽거나 만들지 않는 동작 확인 |
| 오프라인 사용 안내서 링크 | ZIP의 `USER_GUIDE.ko.md`, `CLIENT_SETUP.md`, `CLAUDE_DESKTOP.md` 사이 상대 링크 확인 통과 |
| Windows PowerShell 7.6.5 / 5.1.26100.9444 수명주기·복구 검사 | 아래 그룹별 표 기준 전체 68/68 통과; RC3 업데이트와 중단 기록 복구 포함 |
| 실제 외부 서비스, Windows 자격 증명 저장소, 설치된 클라이언트, 외부 첫 조회 | 이 검증 범위에서 실행하지 않음 |

위 패키지 검사는 복구 호환성 수정이 반영된 최종 RC4 후보에서 수행했습니다. 자산 해시와 정확한 목록은 게시 전에 최종 `release-manifest.json` 및 `SHA256SUMS.txt`로 확인하세요. 체크섬은 파일 무결성을 대조하며 서명이나 게시자 인증을 대신하지 않습니다.

### Windows PowerShell 수명주기 검사

각 수명주기 그룹은 PowerShell 7.6.5 Core와 Windows PowerShell 5.1.26100.9444 Desktop에서 각각 실행했습니다. 각 그룹의 양쪽 결과가 통과했습니다.

| 검사 그룹 | 각 런타임 | 두 런타임 합계 |
| --- | ---: | ---: |
| 기본 설치·업데이트·제거 | 7/7 | 14/14 |
| 경로·reparse 검사 | 12/12 | 24/24 |
| 복구 수명주기 | 9/9 | 18/18 |
| 루트 생성 reparse 검사 | 1/1 | 2/2 |
| 루트 lease 검사 | 1/1 | 2/2 |
| RC3 ZIP에서 RC4 ZIP으로 업데이트 | 1/1 | 2/2 |
| RC3 중단 저널 호환성 회귀 | 3/3 | 6/6 |
| **합계** | **34/34** | **68/68** |

RC3 저널 회귀는 중단된 RC3 복구를 이어 RC4 업데이트하는 흐름을 통과했고, 10개 파일 구성과 혼합된 9개 파일 구성은 거부했습니다. 격리된 합성 설치 경로와 고정한 ZIP 자산만 사용했으며 실제 설치나 서비스 설정을 건드리지 않았습니다.

## UI 범위

합성 helper를 사용한 데스크톱 브라우저 확인은 1232×1156 창에서 한국어/영어 전환, 목차 이동, 요청문 복사 확인, MCP 예시 펼치기, 설정과 준비 상태 링크를 포함했습니다. 브라우저 콘솔 오류는 관찰되지 않았고, 가이드 화면 범위의 독립 시각 검토는 SHIP 판정을 받았습니다. 이 검토는 가이드 페이지에 한정되며 전체 onboarding 흐름이나 실제 서비스·클라이언트 연결의 점검이 아닙니다.

사용·수용 범위는 데스크톱 창이며 좁은 데스크톱 창을 포함합니다. 모바일은 사용하지 않으며 수용 기준이 아닙니다. Go 핸들러 테스트는 페이지 응답과 정적 속성을 확인하고, 브라우저 검토는 화면 구성과 페이지 상호작용만 확인합니다.

## 실제 환경에서 별도 확인할 항목

- 실제 서비스 endpoint, 계정 권한, 토큰 유형, TLS·proxy·VPN 동작
- Windows Credential Manager의 저장·조회·회전·정리 동작
- 실제 Codex CLI, Codex 기능을 갖춘 ChatGPT 데스크톱 앱, Claude Desktop 등 선택한 클라이언트의 설치·server/tool 표시·요청
- 선택한 실제 비운영 서비스에 대한 성공 MCP 조회와 앱 준비 상태의 first-read 표시

각 환경의 확인 방법은 [수용 체크리스트](USER_ACCEPTANCE_CHECKLIST.md), 앱에서 따라 할 단계는 **사용 가이드** 또는 ZIP 안의 `USER_GUIDE.ko.md`를 참고하세요. 클라이언트 지원 범위는 ZIP 안의 `CLIENT_SETUP.md`에서 확인하고, 일반 ChatGPT 대화나 Work 연결까지 검증한 것으로 해석하지 마세요.
