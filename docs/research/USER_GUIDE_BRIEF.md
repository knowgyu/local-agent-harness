# 사용자 가이드 surface brief

**기록일:** 2026-10-13

**상태:** 구현 후 전략 기록. 구현 전에 합의·승인된 brief로 간주하지 않는다.

**Mode:** Read

**범위:** Windows 데스크톱 앱의 정적 `/guide` 안내 페이지. 저장소의 제품 범위는 [PRODUCT.md](../../PRODUCT.md)를 따른다.

## THESIS

사용자가 서비스 한 곳을 등록하는 단계부터 연결된 AI 앱에서 첫 외부 읽기를 직접 확인하는 단계까지 따라갈 수 있게 한다. 설정, 확인 요청, 등록, MCP 호출의 차이를 매 단계에서 분명히 알려 주고 사용 사례와 복사 가능한 실행 예시를 함께 제공한다.

## OWN-WORLD

기존 앱의 밝은 표면, 남색 탐색 막대, 시스템 글꼴과 익숙한 입력 컨트롤을 이어 간다. 이 안내서는 기존 제품 화면에 붙는 문서 화면이다. 별도 시각 세계를 도입하거나 전역 디자인 시스템을 정하지 않는다.

## STORY

한 서비스부터 시작해 주소 형태를 확인하고, 후보와 자격 증명을 검토하고, 진행 상황을 저장하거나 임시 연결을 확인한 뒤, 고정된 작업 범위를 확인하고 대상을 등록한다. 이어서 AI 클라이언트 연결을 직접 설정하고 읽기 요청을 붙여 넣은 다음, 준비 상태에서 실제 성공한 첫 읽기를 확인한다. 연결 테스트, 목록 조회, MCP 도구 표시, 외부 서비스 읽기는 서로 다른 결과로 설명한다.

## FIRST VIEWPORT

한국어를 기본 언어로 두고 “서비스 하나를 등록하고, 첫 읽기까지”를 페이지 제목으로 사용한다. 첫 화면에서 이 안내가 설정과 실행 예시를 보여 주며 서비스 연결이나 도구 실행을 대신하지 않는다는 점을 알린다. 대상 등록과 AI 앱 설정으로 이어지는 링크, 페이지 목차, 기대 결과를 둔다.

## FORM

읽기 중심의 두 열 구성으로, 왼쪽에는 고정 목차를 두고 오른쪽에는 폭을 제한한 문서를 배치한다. 구현된 한국어·영어 문구와 선택 가능한 코드 예시, 복사 동작, GitHub·Jenkins·Dashboard 사용 사례, 추가 Harbor·서비스 묶음·SSH·Python 안내, AI 클라이언트와 문제 해결 안내를 포함한다. 서버는 GET `/guide`에 현재 언어와 CSP nonce를 전달해 템플릿을 렌더링한다. 페이지는 설정·자격 증명 저장소·클라이언트 상태를 읽거나 제공자에 접속하지 않고 예시를 실행하지 않는다.

## FINISH

이번 작업은 정적 가이드, 문서 링크, 보안·동작 검토, 독립 화면 리뷰와 검증 기록이 완료되면 닫는다. 실제 서비스·자격 증명 저장소·AI 클라이언트 설치와 첫 외부 읽기의 현장 검증은 별도 작업이다.
