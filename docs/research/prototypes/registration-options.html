데모 범위와 아직 확인하지 않은 내용
  • 인증 상태와 서비스 조회 결과는 선택한 fixture에서 만든 예시입니다. 실제 서비스 성공, 설치 버전, 권한 또는 연결 상태를 확인하지 않습니다.
  • ChatGPT Desktop과 Claude Desktop은 선호 앱으로만 표시됩니다. 실제 설치 경로와 도구 호출은 검증되지 않았습니다. 현재 CLI 대체 경로로는 Codex CLI를 표시합니다.
  • 초안은 이 탭의 메모리에서 일반 설정만 유지하며, 새로고침하거나 탭을 닫으면 사라집니다. 비밀값은 입력·저장하지 않습니다.
  • Dashboard 1.7.0은 사용자 보고입니다. upstream v1.7.0과 별도 web/v1.7.0 구성 요소가 존재하므로, 설치된 구성 요소와 버전 출처를 확인하기 전 인증 계약은 미확인입니다. 로그인 입력과 응답의 형식·용도를 확인하고, 응답을 Authorization Bearer 값으로 복사하지 않습니다.
