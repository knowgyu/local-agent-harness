Preview saved settings JSON

Select one .json file created by Local Agent Harness, up to 1 MiB. Versions 4 through 9 are supported for preview; versions 5 through 9 include Python task counts, and version 9 includes SSH target counts. The browser sends the selected file to this local app; its actual local path cannot be verified. The preview shows the schema version and record counts only. It omits target/task names, paths, URLs, IDs, usernames, credential references, approval details, history, and raw content. Preview does not import or save settings, read or write credentials, or contact a service.

Preview JSON repository strings

Select one .json file, up to 1 MiB. The browser sends the selected file to this local app; its actual path is unverified. The preview scans exact whole JSON string values and ignores JSON keys. String values over 4 KiB are skipped. It makes no conversation schema or conversation-count support claim. It shows repository strings only; it never shows raw JSON, source strings, URLs, or registered target names or IDs. Results with more than 32 candidates are rejected. Every candidate has fixed low confidence. An exact match to an enabled registered GitHub target is shown for manual review only. Preview does not select a target, save settings, access a network service, or read or write credentials.

Preview an existing Git remote

Select a file named config. The app receives only its filename and cannot verify whether it came from the project’s .git folder. Only the selected file, up to 64 KiB, is sent to this local app. Includes are not followed. Preview does not save settings, create targets, or change permissions.

Preview SSH aliases

Preview does not run commands, contact a service, change settings, or read or write credentials.

Registered Python tasks

Before showing the one-time local browser approval page, the app checks the saved SHA-256 fingerprints of the .exe and .py files; it checks them again immediately before launch. Missing, unreadable, oversized, or changed files block start. A file may still change after the final check, so this is not race-free. Deny, cancel, timeout, or browser failure also prevents execution. The page shows the task name and, when configured, the secret environment variable name, but not paths or secret values. UNC and device-namespace paths are rejected; mapped network drives are not identified. The selected .exe is launched as saved; the app does not verify that it is Python. The script runs with this Windows user's permissions and can read or change local files or contact the network; this is not a sandbox. Files over 256 MiB (.exe) or 16 MiB (.py) cannot be registered. Review and confirm new, changed, or drifted files before saving. MCP cannot supply arguments or environment values. A configured secret is loaded only after approval and task recheck, then passed to the task root process in its configured environment variable; descendants may inherit it. Standard output and error may be included in the current MCP response up to 8 KiB per stream after best-effort filtering of the configured task secret and known credential patterns. A stream that exceeds the cap is omitted and marked truncated. If decoding, filtering, or process cleanup cannot be confirmed, both streams are omitted. Output is not stored in settings, logs, or task history; filtering cannot guarantee removal of every secret. On Windows 10 and newer, the root process enters a private Job Object at process creation. The app terminates ordinary CreateProcess descendants when the root exits, fails, times out, or is cancelled, and limits execution to two active task trees and 30 seconds per call. If cleanup cannot be confirmed, this app blocks later registered task launches until it restarts. Processes created through mechanisms such as Win32_Process.Create are outside this containment.

Task names appear in the local MCP catalog and approval page. Do not include secrets or file paths in the name.

Connect an MCP client (CLI guide)

These examples use CLI commands to register this executable as a local stdio process. Replace the example path with the absolute path to your built executable. Codex CLI, the ChatGPT desktop app, and the Codex IDE extension share MCP configuration on the same host. This guide covers CLI setup, not separate desktop or IDE setup steps. The client-registration panel checks supported CLI settings when this settings page opens and when you refresh. You must explicitly request review, backup, or registration changes. It cannot verify an AI app connection or tool call.

Optional check-ins below record only what you report seeing. They stay in this page until it reloads, are not saved to app settings, and do not mean this app verified a client connection.

To check a client tool call without contacting a saved service, start with registered_targets or registered_service_bundles. These catalogs list local registrations only.

Codex CLI

Install from the official Codex CLI guide, then check the installed version with codex --version.

codex mcp add local-agent-harness -- "C:\path\to\local-agent-harness.exe" --mcp
codex mcp list

Start a Codex CLI session and use /mcp to inspect active servers and tools. codex mcp list shows saved configuration. See the official MCP guide.

If the server is missing from an already-open session, start a new Codex CLI session. A saved-list entry alone does not confirm an active connection.

The ChatGPT desktop app and Codex IDE extension share this same-host configuration. If the server still does not appear, use the Restart control if that client provides one. This app does not detect whether the client reloaded or connected.

Optional progress check-in

Claude Code CLI

Install from the official Claude Code guide, then open a new PowerShell window and check the installed version with claude --version.

claude mcp add --scope user --transport stdio local-agent-harness -- "C:\path\to\local-agent-harness.exe" --mcp
claude mcp list
claude mcp get local-agent-harness

Use /mcp in a Claude Code session to inspect status and tools. This procedure does not configure Claude Desktop. See the official MCP guide.

If the server is disconnected, check its status in /mcp and run claude mcp get local-agent-harness. If it still fails, start a new Claude Code CLI session. A saved-list entry alone does not confirm an active connection.

Gemini CLI

Install from the official Gemini CLI guide, then check the installed version with gemini --version.

gemini mcp add --scope user local-agent-harness "C:\path\to\local-agent-harness.exe" -- --mcp

Use /mcp list to inspect a running session or /mcp reload to reload servers. Stdio servers are reported as Connected only when the current folder is trusted. If Disconnected, review the folder before using gemini trust. See the official MCP guide.
