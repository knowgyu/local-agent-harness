                  Registered Python tasks

                  Before showing the one-time local browser approval page, the app checks the saved SHA-256 fingerprints of the .exe and .py files; it checks them again immediately before launch. Missing, unreadable, oversized, or changed files block start. A file may still change after the final check, so this is not race-free. Deny, cancel, timeout, or browser failure also prevents execution. The page shows the task name and, when configured, the secret environment variable name, but not paths or secret values. UNC and device-namespace paths are rejected; mapped network drives are not identified. The selected .exe is launched as saved; the app does not verify that it is Python. The script runs with this Windows user's permissions and can read or change local files or contact the network; this is not a sandbox. Files over 256 MiB (.exe) or 16 MiB (.py) cannot be registered. Review and confirm new, changed, or drifted files before saving. MCP cannot supply arguments or environment values. A configured secret is loaded only after approval and task recheck, then passed to the task root process in its configured environment variable; descendants may inherit it. Standard output and error may be included in the current MCP response up to 8 KiB per stream after best-effort filtering of the configured task secret and known credential patterns. A stream that exceeds the cap is omitted and marked truncated. If decoding, filtering, or process cleanup cannot be confirmed, both streams are omitted. Output is not stored in settings, logs, or task history; filtering cannot guarantee removal of every secret. On Windows 10 and newer, the root process enters a private Job Object at process creation. The app terminates ordinary CreateProcess descendants when the root exits, fails, times out, or is cancelled, and limits execution to two active task trees and 30 seconds per call. If cleanup cannot be confirmed, this app blocks later registered task launches until it restarts. Processes created through mechanisms such as Win32_Process.Create are outside this containment.

                  Task names appear in the local MCP catalog and approval page. Do not include secrets or file paths in the name.
